# Glossário de termos da interface (UI)

Termos usados de forma consistente no frontend para evitar ambiguidade.

| Termo na UI | Significado |
|-------------|-------------|
| **Avaliação** | Uma sessão de anamnese/avaliação com um paciente (corresponde a uma “Session” no backend). Ex.: lista “Avaliações”, botão “Nova avaliação”. |
| **Questionário** | Template de perguntas (modelo reutilizável). Ex.: menu “Questionários”, “templates de questionário”. |
| **Anamnese** | O fluxo de perguntas e respostas durante uma avaliação. Ex.: “Continuar anamnese”, tela “Anamnese”. |
| **Ver detalhes** | Abre a página de detalhe do recurso (ex.: avaliação, paciente). |
| **Ver insights** | Abre a página de insights da avaliação. |
| **Continuar anamnese** | Retoma o preenchimento do questionário da avaliação. |
| **Plano** | Plano de dieta ou de treino atribuído a um paciente. |
| **Agendamentos** | Questionários agendados para envio ao paciente. |
